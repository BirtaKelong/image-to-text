Key Application Features

📷 Advanced Image & PDF Studio

  • Support for JPG, JPEG, PNG, WEBP, BMP, and multi-page PDF documents.
  • Interactive image cropping powered by Cropper.js.
  • 90°, 180°, and 270° clockwise image rotation with center pivot calculation.
  • Real-time brightness & contrast adjustment filters for scanned document enhancement.
  • Page-by-page PDF navigation with high-resolution rendering.

🧠 Multilingual OCR Recognition

  • Pre-trained LSTM neural network models for English, Hindi, Bengali, and Assamese.
  • Real-time progress reporting across worker initialization and text extraction stages.
  • Graceful cancellation and memory cleanup with Web Worker termination.

📝 Integrated Text Editor & Multi-Format Export

  • Live word, character, non-whitespace character, and line count statistics.
  • Estimated reading time computation.
  • In-text search and navigation (Find / Next / Previous).
  • One-click copy to clipboard with fallback.
  • Export to .TXT (with UTF-8 BOM), .PDF (via jsPDF), and .DOCX (via docx library).

About & Data Privacy

🔒 100% Client-Side Privacy Guarantee

This application operates entirely inside your web browser. Neither your images, PDF documents, nor the extracted text are ever transmitted to any remote server, cloud API, or third-party database.

⚡ How It Works

Text extraction is powered by Tesseract.js compiled to WebAssembly (Wasm) and executed inside an isolated browser Web Worker. Document rendering is performed on HTML5 Canvases using the browser's hardware-accelerated graphic pipeline.

💻 Offline Capability

Once the language traineddata model is cached in browser IndexedDB/Cache storage, the OCR engine can run even when disconnected from the internet.
